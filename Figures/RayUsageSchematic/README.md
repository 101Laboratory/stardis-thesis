# 射线使用场景示意图（二维截面）

**文件名**: `RayUsageSchematic.pdf` (SVG → PDF)  
**放置位置**: §3.4.1 节首，公式展开前  
**尺寸**: 0.85\textwidth，横向  

## 内容描述

一张二维截面示意图，展示各物理模块中三类几何查询（RT/CP/ENC）的射线使用场景。

### 场景布局（从左到右）

- 左侧：开放环境（天空/太阳），标注 EXT 子流程区域
- 中间上方：Solid A 壁体截面（含外表面和内表面）
- 中间：Fluid A 封闭腔体（Enc A）
- 中间下方：Solid B 壁体截面
- 右下角：Fluid B / Solid B 的固-固接触面

### 各模块射线标注

1. **RAD（辐射传播）**：
   - 从腔体内某点出发的 RT 射线（实线箭头，红色），标注"RT: 余弦采样弹射"
   - 射线命中 Solid A 内表面，标注 BND 入口

2. **CND-DS（δ-球面游走）**：
   - 从固体内某游走点出发的 ±Ω 双向 RT 射线对（实线箭头，蓝色），标注"RT: 双向步长估计"
   - ENC 查询标注（点划线，绿色），标注"ENC: 位置腔体归属验证"

3. **CND-WoS（经典 WoS 游走）**：
   - 从固体内某游走点到最近面的 CP 投影（虚线箭头，橙色），标注"CP: 最近面距离"
   - 第二次 CP 验证查询（虚线箭头，橙色），标注"CP: 位置验证"
   - 条件性 RT 回退射线（实线箭头，蓝色/半透明），标注"RT: 回退修正（条件性）"

4. **BND-ENC（腔体归属）**：
   - 从界面点发出的 6 方向轴对齐射线（点划线，绿色），标注"ENC: 6-ray 投票"

5. **BND-SF（固-流界面）**：
   - 法线内侧 δ-重注入 RT 射线（实线箭头，紫色），标注"RT: δ-重注入"
   - null-collision 辐射子路径 RT 射线（实线箭头，紫色/虚线），标注"RT: null-collision 子射线"

6. **BND-EXT（外部环境）**：
   - 太阳阴影射线（实线箭头，金色），标注"RT: 太阳阴影测试"
   - 天空漫射采样射线（实线箭头，天蓝色），标注"RT: 天空漫射"
   - 遮挡验证射线（实线箭头，灰色），标注"RT: 遮挡验证"

### 视觉编码

| 查询类型 | 线型 | 颜色系 |
|----------|------|--------|
| RT（射线追踪） | 实线箭头 | 红/蓝/紫/金 |

| ENC（腔体归属） | 点划线 | 绿色 |
